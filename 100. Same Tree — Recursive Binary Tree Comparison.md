# Same Tree — LeetCode 100

## Intuition

We need to check whether two binary trees are exactly the same.

For two trees to be the same:

* Both nodes should be `nullptr` at the same position.
* If only one node is `nullptr`, the trees are different.
* The values of corresponding nodes must be equal.
* Their left subtrees must also be the same.
* Their right subtrees must also be the same.

We can solve this recursively by comparing the corresponding nodes of both trees.

## Approach

1. If both `p` and `q` are `nullptr`, return `true` because both trees end at the same position.
2. If one of them is `nullptr`, return `false` because their structures are different.
3. Compare the values of the current nodes.
4. Recursively compare the left subtrees.
5. Recursively compare the right subtrees.
6. The trees are the same only when the current values, left subtrees, and right subtrees are all the same.

## Complexity

* Time complexity: **O(n)**

  Each node is checked once.

* Space complexity: **O(h)**

  `h` is the height of the tree because of the recursive call stack.

## Code

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */

class Solution {
public:
    bool isSameTree(TreeNode* p, TreeNode* q) {
        if (p == nullptr && q == nullptr) {
            return true;
        }

        if (p == nullptr || q == nullptr) {
            return false;
        }

        return (p->val == q->val) &&
               isSameTree(p->left, q->left) &&
               isSameTree(p->right, q->right);
    }
};
```
