# Intuition

A symmetric binary tree should be a mirror image of itself.

So instead of checking whether the left and right subtrees are individually symmetric, we compare them with each other as mirrors.

For two nodes `t1` and `t2`:

* If both are `nullptr`, they are symmetric.
* If only one is `nullptr`, they are not symmetric.
* Their values must be equal.
* `t1->left` must match `t2->right`.
* `t1->right` must match `t2->left`.

# Approach

First, handle the case where the root is `nullptr`.

Then call a helper function `isMirror()` with the root's left and right children.

The helper recursively compares the two subtrees:

1. Check if both nodes are `nullptr`.
2. Check if only one node is `nullptr`.
3. Check whether their values are equal.
4. Compare the outer children:
   `t1->left` with `t2->right`.
5. Compare the inner children:
   `t1->right` with `t2->left`.

If all these conditions are true, the tree is symmetric.

# Complexity

* Time complexity: `O(n)`

Each node is visited once.

* Space complexity: `O(h)`

The recursive call stack can grow up to the height `h` of the tree. In the worst case, `h = n`.

# Code

```cpp
class Solution {
public:

    bool isSymmetric(TreeNode* root) {
        if(root == nullptr){
            return true;
        }

        return isMirror(root->left, root->right);
    }

    bool isMirror(TreeNode* t1, TreeNode* t2) {
        if(t1 == nullptr && t2 == nullptr)
            return true;

        if(t1 == nullptr || t2 == nullptr)
            return false;

        return (t1->val == t2->val) &&
               isMirror(t1->left, t2->right) &&
               isMirror(t1->right, t2->left);
    }
};
```
